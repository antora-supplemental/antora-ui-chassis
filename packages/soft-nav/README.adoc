= SoftNav

Chassis UI component: same-origin soft navigation for Antora hubs.

== Include

*Preferred:* register `@antora-supplemental/chassis-compose` (injects `soft-nav.js` before `soft-nav-context`) or require `@antora-supplemental/soft-nav` alone on the playbook.

*Manual:* copy `js/soft-nav.js` into hub `supplemental-ui/js/` and load **before** consumer scripts:

----
<script src="{{{uiRootPath}}}/js/soft-nav.js" defer></script>
<script src="{{{uiRootPath}}}/js/site-nav-tree-current.js" defer></script>
----

== API

* `SoftNav.on('before'|'loaded'|'failed', handler)` — returns unsubscribe
* `SoftNav.registerRegion({ id, extract(doc), apply(fresh, ctx) })`
* `SoftNav.navigate(url)`
* `SoftNav.transition` — `'crossfade'` (default) or `'none'`

DOM events: `soft-nav:before`, `soft-nav:loaded`, `soft-nav:failed`.
Compat: also fires `doc-nav:loaded` on success.

Built-in regions: `mast`, `nav`, `article`. SoftNav does **not** hard-call nav-tree / mermaid / math — those subscribe to `loaded`.

Persistent chrome (search omnibox, dock) is **not** swapped — pair SoftNav with link:../soft-nav-context/README.adoc[SoftNavContext] so scope/context tracks each navigation.

== Consumer pattern

Swapped regions (article, in-nav TOC helpers):

----
bindSoftNavContext({
  onBoot: function () { rebind(document) },
  onLoaded: function (ctx) { rebind((ctx && ctx.articleHost) || document) },
})
----

Persistent chrome (search scope in navbar) uses link:../soft-nav-context/ARCHITECTURE.adoc[SoftNavSignals] — SoftNav does not replace those nodes.

Without `bind-soft-nav-context.js`, duplicate the SoftNav + DOM fallback once per script (discouraged for new extensions).
