= SoftNav

Chassis UI component: same-origin soft navigation for Antora hubs. It swaps the page regions and announces each navigation on xref:../ui-bus/README.adoc[UiBus]; it knows nothing about the widgets that react.

== Include

*Preferred:* register `@antora-supplemental/chassis-compose`, or require `@antora-supplemental/soft-nav` alone. Either injects `ui-bus.js` and then `soft-nav.js`.

*Manual:* copy `ui-bus.js` and `soft-nav.js` into hub `supplemental-ui/js/` and load them first, in this order:

----
<script src="{{{uiRootPath}}}/js/ui-bus.js" defer></script>
<script src="{{{uiRootPath}}}/js/soft-nav.js" defer></script>
<script src="{{{uiRootPath}}}/js/site-nav-tree-current.js" defer></script>
----

== Events it publishes

[source,js]
----
UiBus.events.on('nav:before', (ctx) => {})  // { url, push }
UiBus.events.on('nav:loaded', (ctx) => {})  // { url, doc, articleHost }
UiBus.events.on('nav:failed', (ctx) => {})  // { url, error }; a hard load follows
----

== API

* `SoftNav.registerRegion({ id, extract(doc), apply(fresh, ctx) })`
* `SoftNav.navigate(url)`
* `SoftNav.transition`: `'none'` (default) or `'crossfade'`

Built-in regions: `mast`, `nav`, `article`. Persistent chrome (search, dock) is not swapped; it follows the page through `page-state` values on the bus.

== Consumer pattern

[source,js]
----
function rebind (root) { /* render math, diagrams, ... inside root */ }
rebind(document)
UiBus.events.on('nav:loaded', (ctx) => rebind(ctx.articleHost || document))
----
