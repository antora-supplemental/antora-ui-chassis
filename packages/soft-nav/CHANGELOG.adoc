= Changelog

== 0.2.0 - 2026-10-24

* **Breaking:** lifecycle moves to the general bus: `UiBus.events.on('nav:before' | 'nav:loaded' | 'nav:failed', fn)`. `SoftNav.on` and the `soft-nav:*` / `doc-nav:loaded` DOM events are removed, with no aliases. The extension injects `ui-bus.js` ahead of `soft-nav.js`.

== 0.1.3 — 2026-10-21

* **Single SoftNav script tag:** `appendFooterScriptAfter` checks both `footer-scripts` and `footer-content` before insert (fixes duplicate listeners when hubs reference soft-nav in `footer-content`).
* **Forest gate:** `sameComponent` runs against the resolved nav destination (`resolveForestNavHref`), not live `a.href`.

== 0.1.2 — 2026-10-21

* **site-nav-tree forest:** nav-panel `.nav-link` clicks soft-navigate across Antora components when the sidebar has multiple depth-0 roots (`SoftNav.crossComponentForest`, default `'auto'`). Resolves click targets via `siteNavTreeResolveNavLink` when present.

== 0.1.1 — 2026-10-21

* Antora extension `lib/index.js`: publish `js/soft-nav.js` and inject defer script in `footer-content` / `footer-scripts` after `site.js`.
