= diagram-zoom (removed)

This chassis copy-only package was removed after `@antora-supplemental/diagram-lightbox` shipped in link:https://github.com/antora-supplemental/antora-diagram-engines[antora-diagram-engines].

== Adopt instead

* Playbook: `require: '@antora-supplemental/diagram-lightbox'` (`injectAssets: true` default).
* Partials: `{{> diagram-lightbox-styles}}` in head; `{{> diagram-lightbox-scripts}}` in the footer (after SoftNav when present).
* Reference wiring: link:https://github.com/antora-supplemental/facto-stack/tree/main/demo/supplemental-ui/partials[facto-stack demo partials^] and `examples/minimal-playbook.yml`.

Do not copy `site-diagram-zoom.js` / `site-diagram-zoom.css` into new hubs.
