= Minimal UiBus + SoftNav + page-state (Default UI)

Smallest playbook that pairs Antora Default UI with `@antora-supplemental/chassis-compose` at git tag `chassis-v0.2.0`. No supplemental UI files are needed.

== Quick start

[source,shell]
----
pnpm install
pnpm run build
# open build/site/index.html via a static server
----

== What this proves

* `chassis-compose` injects `ui-bus.js`, `soft-nav.js` and `page-state.js` after `site.js`, in that order, and adds the `page-state-context` partial to the article.
* In the browser console: `UiBus.state.get('page.url')` changes and `UiBus.events.on('nav:loaded', console.log)` fires as you click between pages.
