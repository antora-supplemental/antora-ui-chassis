= Default UI paint
:description: Paint layer for the stock Antora Default UI, paired with the chassis light-dark-mode package.

`@antora-supplemental/default-paint` gives sites on the stock Antora Default UI a light and a dark palette.
It is the *paint* layer: colors only. The *chassis* package `light-dark-mode` supplies the switching (no-FOUC hook, saved choice, system preference, toggle) and `color-scheme` the token names; a theme such as Valentus supplies its own paint instead.

== Where it lives and why

Chassis is unstyled by contract, so the palette is not part of `color-scheme`.
It ships as a sibling package, `packages/default-paint`, in the chassis monorepo so it versions and tags next to the mechanism it pairs with (`default-paint-vX.Y.Z`).
It is labelled `layer: paint` in `ui-component.json5`, `antora-registry.md` and `registry-index.json`, and no chassis package depends on it.

== Install

[source,yaml]
----
antora:
  extensions:
    - require: '@antora-supplemental/light-dark-mode'
    - require: '@antora-supplemental/default-paint'
----

Pin: `github:antora-supplemental/antora-ui-chassis#default-paint-v0.1.1&path:packages/default-paint`.

== Design

* `--dp-*` tokens on `:root` (light: the Default UI's own colors, so light mode is unchanged) and `html.dark-theme` (dark: ported from `antora-dark-mode` 1.4.6).
* Default UI selectors read the tokens; dark-only rules cover highlight.js tokens and the masked nav glyphs.
* The chassis token contract (`--valentus-canvas` … `--valentus-accent`) is defined from the palette.
* Not ported (body kit, not paint): nav insets, sticky nav, doc-home cards, VCS logo sizing, float groups.

See `packages/default-paint/README.adoc` for the token table.
