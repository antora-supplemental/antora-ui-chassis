= Asset fingerprint (cache-busting asset URLs)
:description: Cache-busting for any Antora site: ?v=<content hash> on CSS and JS URLs in the built HTML.

`@antora-supplemental/asset-fingerprint` (`packages/asset-fingerprint`) adds `?v=<content hash>` to the CSS and JS URLs (optionally fonts and images) in every built HTML page, after Antora writes the site.

Why: static hosts serve `_/css/site.css` under the same name with a cache lifetime (GitHub Pages: 4 hours), so after a deploy visitors keep the old stylesheet. With a fingerprint, a changed file gets a new URL at once; an unchanged file keeps its URL and stays cached.

It works with any UI bundle (Default UI, Valentus, Skittles, ...): it reads the built files, not theme partials.

== Install

Pin by git tag (chassis convention):

[source,json]
----
"@antora-supplemental/asset-fingerprint": "github:antora-supplemental/antora-ui-chassis#asset-fingerprint-v0.1.0&path:packages/asset-fingerprint"
----

== Antora extension

List it last, so files other extensions write are already on disk:

[source,yaml]
----
antora:
  extensions:
    - require: '@antora-supplemental/asset-fingerprint'
      # all optional:
      hash_length: 10
      fonts: false
      images: false
      exclude: ['_/js/vendor/**']
----

Antora passes keys as written; both `hash_length` and `hashLength` work.

== CLI

[source,sh]
----
antora antora-playbook.yml && asset-fingerprint build/site
asset-fingerprint build/site --hash-length 8 --fonts --exclude '_/js/vendor/**' --base-path /my-repo
----

== Options

[cols="1,1,3"]
|===
| Option | Default | Meaning

| `include` | `_/css/**`, `_/js/**`, `**/search-index.js` | Site-relative globs of assets to fingerprint (`*`, `**`, `?`).
| `exclude` | none | Globs to skip.
| `hashLength` | `10` | Hex characters of the SHA-256 content hash (4-64).
| `fonts` / `images` | `false` | Also fingerprint `_/font/**`, `_/fonts/**` / `_/img/**`.
| `param` | `v` | Query parameter name.
| `basePath` | path of `site.url` | Prefix stripped from site-root URLs (`/repo/_/css/site.css`).
| `pages` | all `*.html` | Globs of pages to rewrite.
| `enabled` | `true` | `false` turns the extension off.
|===

Relative and site-root `href`/`src` values are resolved to files under the output dir. External URLs, missing files, and URLs that already carry `v=` are left alone, so running twice changes nothing. Existing queries and fragments are kept (`a.css?x=1&v=...#top`).

Only HTML is rewritten. `url()` references inside CSS (fonts, images) are not; use `fonts` / `images` for those linked from HTML.

== Programmatic

[source,js]
----
const { fingerprintSite } = require('@antora-supplemental/asset-fingerprint')
fingerprintSite('build/site', { hashLength: 8 }) // { files, urls, assets }
----
