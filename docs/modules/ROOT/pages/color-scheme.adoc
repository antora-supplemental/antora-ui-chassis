= Color scheme and retiring antora-dark-mode

== Status

*Done (2026-10-25).* `antora-dark-mode` is merged into `@antora-supplemental/color-scheme` 0.1.2 (tag `color-scheme-v0.1.2`) and deprecated.
Valentus places the toggle and owns its palettes; it no longer copies dark-mode files.

== Split of responsibility

* *Chassis* (`packages/color-scheme`) — the mechanism, with no colors: no-FOUC head hook, saved choice, `prefers-color-scheme` handling, `html.dark-theme` / `data-theme` / `data-color-scheme-mode` hooks, token names, the switch transition, toggle behavior and a11y.
* *Body kit* — where the toggle sits and how it looks (Valentus places `#theme-toggle` in its header).
* *Paint* — actual light/dark token values (`--valentus-canvas`, `--valentus-ink`, …) and every other colored rule.

See the package README for install, hooks and the `ColorScheme` API.

== Parity with antora-dark-mode 1.4.6

`color-scheme` replaces `antora-dark-mode`. Every row must be equal or better before the old package is retired.
"Layer" says where the old behavior now lives: *chassis* (this package, no colors), *body kit* (Valentus places and dresses the toggle), *paint* (palette colors).

== Retirement of antora-dark-mode

`antora-dark-mode` is deprecated. Its README carries a migration section:

. Remove the `antora-dark-mode` UI bundle, supplemental files or ui-module.
. Add `require: '@antora-supplemental/color-scheme'` to the playbook.
. Keep or add paint that defines both palettes on `html.dark-theme` (Valentus does).
. Rename `valentus-theme-animating` / `valentus-theme-vt` in custom CSS to `color-scheme-animating` / `color-scheme-vt`.

Saved user choices carry over because the storage keys are unchanged.

== CSS short-circuit fallbacks

Chassis names the `--valentus-*` tokens; paint defines them for both schemes.
Every consumer (chassis components, body kit, paint users, bolt-ons) styles with:

----
color: var(--valentus-ink, CanvasText);
background: var(--valentus-canvas, Canvas);
----

so a region yanked out of the stack still paints something readable.
