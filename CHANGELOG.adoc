= Changelog

== default-paint-v0.1.0 - 2026-10-25

* **New `default-paint` 0.1.0 (paint layer, not chassis):** light and dark palette for the stock Antora Default UI, as an Antora extension that links `css/default-paint.css` after `color-scheme.css`. Light keeps the Default UI's colors; dark is ported from `antora-dark-mode`. Closes the "no default paint" gap left by `color-scheme` 0.1.0. Registry entry `layer: paint`.

== color-scheme-v0.1.2 - 2026-10-25

* *color-scheme:* fix 0.1.1 crash; `register({ config })` so options are read and `this` is the generator context. Do not pin 0.1.1.

== color-scheme-v0.1.1 - 2026-10-25

* *color-scheme:* playbook options were ignored (`register` declared zero parameters); fixed.

== color-scheme-v0.1.0 - 2026-10-25

* **`color-scheme` 0.1.0:** now a published Antora extension (`@antora-supplemental/color-scheme`) and the replacement for `antora-dark-mode`. It merges the old mechanism (no-FOUC head hook, saved choice under the same `antora-theme-mode` keys, system preference with override expiry, View Transition switch, accessible toggle binding) and adds the `ColorScheme` API, `UiBus.state` publishing and toggle re-binding after soft navigation.
* **Breaking:** `css/color-scheme.css` carries no colors any more; paint defines both palettes. Transition classes are `color-scheme-animating` / `color-scheme-vt`.
* Docs: `color-scheme.adoc` has the parity table against `antora-dark-mode` and the layer each feature moved to.

== chassis-v0.2.0 - 2026-10-24

* **New `ui-bus`:** a general event bus (`UiBus.events` for transient signals, `UiBus.state` for persistent values) with no feature knowledge. Every chassis package now talks through it.
* **`soft-nav` 0.2.0:** publishes `nav:before`, `nav:loaded`, `nav:failed` on the bus. `SoftNav.on` and the `soft-nav:*` / `doc-nav:loaded` DOM events are removed.
* **`page-state` 0.1.0:** replaces `soft-nav-context`; publishes `page.*` values. `SoftNavContext`, `SoftNavSignals` and `bindSoftNavContext` are removed.
* **`chassis-compose` 0.2.0:** bundles all three. No compatibility aliases anywhere.

== Unreleased

* `soft-nav` Antora extension + `chassis-compose` **0.1.1** bundles runtime inject (meta tag `chassis-v0.1.1`).
* `soft-nav-context` **0.2.0**: `SoftNavSignals` canonical API for persistent chrome; `bindSoftNavContext` routes `onContext` through signals.
* Registry metadata for `soft-nav-context` and `chassis-compose` (`antora-registry.md`, `registry-index.json`, `antora-registry-topics.json5`).
* Example `examples/minimal-soft-nav` — Default UI + copied `soft-nav.js` + `chassis-compose` @ `chassis-v0.1.0`.
* Remove copy-only `packages/diagram-zoom` assets (`site-diagram-zoom.js/css`, `ui-component.json5`); keep `packages/diagram-zoom/README.adoc` redirect to `@antora-supplemental/diagram-lightbox`.
* README and `chassis-compose` docs no longer list diagram-zoom as an active chassis package.
